# Roblox Script

This project is a Roblox script that moves a part when a player touches it. It is designed for Roblox game developers who want to add interactive elements to their games. The script is written in Lua and is intended to be used within the Roblox Studio environment.

## Install

1. Open your Roblox project in Roblox Studio.
2. Create a new script in the ServerScriptService.
3. Copy the contents of the MovePartOnTouch.lua file into the new script.
4. Save the script.

## Use

1. Insert a part into your game.
2. Attach the script to the part.
3. Playtest your game. When a player touches the part, it will move up by 5 studs.
